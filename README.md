## 🔑 Key Insights

- Total transaction volume reached **250K**, with a total transaction value of **327.94M**.
- Overall transaction success rate was approximately **95.05%**.
- **P2P and P2M** transactions contributed the highest transaction value.
- **SBI** recorded the highest transaction volume among the analyzed banks.
- **4G** was the most widely used network type for transactions.
- **Android** accounted for the majority of transactions among device types.
- **Evening and Afternoon** were the most active transaction time slots.
- **Weekday** transactions were significantly higher than weekend transactions.
- **Recharge transactions** showed the highest fraud rate among transaction types.
- **Kotak** recorded the highest fraud rate among the analyzed banks.
